# Local Fork of SCVim

CAUTION: This is a heavily modified fork. I only kept the syntax highligting.

For the full plugin and documentation, refer to the upstream repo at
[supercollider/scvim](https://github.com/supercollider/scvim).


## INSTALL

1. Copy [ftdetect/supercollider.vim](ftdetect/supercollider.vim) into your
   `$HOME/.vim/ftdetect` directory.
2. Copy [syntax/supercollider.vim](syntax/supercollider.vim) into your
   `$HOME/.vim/syntax` directory.
